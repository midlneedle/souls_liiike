# Компаньон · Web

Интерактивный музыкальный прототип на React, TypeScript, Vite, Motion и Three.js. Проект запускается самостоятельно: исходный Swift-проект для установки и сборки не требуется. Аудио и фоновый Metal-шейдер не включены; Play меняет только состояние интерфейса.

Интерфейс оформлен по готическому референсу: каменный фон, металлические орнаменты, текстурные кнопки и приглушённые цветные акценты. Исходные текстуры дополнены тремя подготовленными ассетами. Большая кнопка собрана по компоненту из Paper: постоянные металлический обод и белый диск со свечением, независимые значки Play/Pause. Старая цельная картинка кнопки заменена этой сборкой. Реплики набраны Source Serif Pro Regular: 26 px, line-height 100%, letter-spacing −2%; переносы измеряются по загруженному шрифту. Очередь и настройки используют те же материалы и остаются самостоятельными bottom sheet поверх главной.

## Запуск

Требуется Node.js 22.13+ и npm. Файл `.nvmrc` задаёт Node.js 22.

Из корня репозитория:

```sh
npm ci
npm run dev
```

Открыть адрес из вывода сервера, обычно `http://localhost:5173`. Для проверки на телефоне использовать сетевой адрес из того же вывода; устройства должны находиться в одной сети.

## Проверки и сборка

```sh
npm test
npm run check:render
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт `dist/`. Эту папку можно разместить на статическом хостинге, в том числе в подпапке сайта. Для просмотра нужен HTTP-сервер, например `npm run preview`.

Тесты проверяют механику боя, распознавание жестов, карусель, раскладку, геометрию и отрисовку обложек. `check:render` проверяет начальный React-рендер и наличие ресурсов. Автоматические проверки не заменяют визуальную проверку WebGL и жестов в Safari на телефоне.

## Поведение прототипа

- Бесконечная карусель из девяти карточек с постоянными репликами ассистента, очередь и настройки потока.
- Потоки Инди, Электроника, Хип-хоп и «Любимое» имеют обложки в едином стиле каменных и металлических эмблем с цветными градиентами. Кнопка «Настроить» под «Моим потоком» удалена.
- Фоны этих обложек — гладкие градиенты по исходному «Любимому»; фактура камня и металла присутствует только на эмблемах. Реплики ограничены двумя строками и сокращены под этот формат. Размер обложки и раскладка не зависят от длины реплики; на очень коротком экране сохраняется минимальная высота композиции с прокруткой страницы.
- Свайп миниплеера доходит до половины ширины и пружиной возвращается обратно; трек не переключается.
- Neverender и Billie Eilish скрывают мимиков. Пропущенная буква в названии выдаёт подмену. Тап по обложке в коротком окне перед укусом отражает мимика.
- Сохранение трека превращает текущий экран в бой: карусель исчезает, сердце становится рукояткой меча, обложка — головой монстра.
- Управление боем — свайпы по всему полю. Своевременный свайп парирует замах; свайпы по открытому противнику наносят серию ударов. Меч реагирует во время движения пальца, смена направления продолжает серию. Стрелки клавиатуры дублируют свайпы.
- Полос здоровья и текстовых подсказок в бою нет. Три состояния противника видны по повреждениям, осанке и движениям.
- Монстр и оружие выполнены в PS1-стиле; обложки рисуются отдельно в полном разрешении. При недоступности WebGL используется упрощённое представление.
- После победы трек сохраняется, сердце возвращается в миниплеер. После первого сохранения недруг подкидывает свой трек в очередь.

Состояние хранится в памяти вкладки. Перезагрузка возвращает демонстрацию к началу. Док содержит «Главная», «Каталог», «Моё»; отдельные страницы для последних двух пунктов не реализованы.

Анимация реплик перенесена из варианта `stream` проекта [llmonboard, коммит 8c749d6](https://github.com/midlneedle/llmonboard/blob/8c749d65730cc9cba42714495d389a537609d3b3/llmonboard/Onboarding/AnimatedQuestionText.swift): первое слово набирается медленнее остальных, первая строка проходит через фиксированный центр, последующие строки мягко перецентрируют блок по высоте. При смене реплики текст стирается в обратном порядке за 0,4 с. Тап по реплике повторяет появление. Блюра и курсора нет; reduced motion показывает текст сразу. Тайминги и расчёт движения находятся в `src/streamText.ts`.

## Структура

- `src/App.tsx` — основной экран и сценарии прототипа.
- `src/Carousel.tsx`, `src/carouselGeometry.ts`, `src/nativeLayout.ts` — карусель и раскладка.
- `src/MiniPlayer.tsx`, `src/NativeSpeech.tsx`, `src/NativeSettings.tsx` — компоненты интерфейса.
- `src/DuelView.tsx`, `src/duel.ts`, `src/battle/` — интерфейс, механика и 3D-модель боя.
- `src/MimicStage.tsx`, `src/mimic/` — мимик и отрисовка.
- `src/data.ts`, `src/*.json` — карточки, метаданные треков, палитры, реплики и иконки.
- `public/assets/` — обложки, шрифты и остальные ресурсы интерфейса.
- `src/gothic.css`, `src/gothicAssets.ts`, `src/gothicTheme.ts` — оформление, текстуры и палитры.
- `textures/` — подключённые текстуры интерфейса, исходники генерации и референс.
- `font/` — Source Serif Pro и лицензия. Сборка включает используемые начертания.
- `tests/` — автоматические проверки.
- `scripts/check-render.mjs` — проверка начального рендера.
- `scripts/preview-*.mjs` — диагностические проекции 3D-моделей без браузера; JSON записывается в `/tmp/`.
- `scripts/export-native-palettes.py` — вспомогательный экспорт палитр из оригинального Swift-проекта. Только для разработки на macOS при наличии исходников рядом; для запуска веб-версии не нужен. Готовые палитры находятся в `src/palettes.json`.
- `vendor/three-0.180.0.tgz` — локальная зависимость Three.js с лицензией внутри архива. Архив должен храниться в репозитории: на него ссылаются `package.json` и lock-файл.

## Файлы в Git

Исходники, ресурсы, тесты, конфигурация, `package-lock.json` и `vendor/` входят в репозиторий. `node_modules/`, `dist/`, локальные `.env`, логи, файлы macOS и локальные скриншоты исключены через `.gitignore`. Зависимости воспроизводятся командой `npm ci`.
