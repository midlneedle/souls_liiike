# Компаньон · Web

Музыкальный прототип на React, TypeScript, Vite, Motion и Three.js. Запускается самостоятельно. Начальный экран — выбор трёх сценариев: «Мимик», «Дизлайк», «Вторжение».

## Запуск

Требуется Node.js 22.13+ и npm. Файл `.nvmrc` задаёт Node.js 22.

```sh
npm ci
npm run dev
```

Открыть адрес из вывода сервера, обычно `http://localhost:5173`. Для телефона использовать сетевой адрес из того же вывода; устройства должны находиться в одной сети.

## Сценарии

- **Мимик.** Главная с большой иллюстрацией, отдельной прозрачной рамкой и заголовком «Музыкальный поток для рилакса». Зубчиков и карусели разделов нет. Мини-плеер и док переиспользованы. Первый Play будит мимика: он появляется вокруг самой кнопки, кусает её и возвращает на прежнее место. В коротком окне перед укусом повторный тап парирует. Обложка остаётся на месте. Обычный Play меняет состояние интерфейса без загрузки аудио.
- **Дизлайк.** Превью противника с обложкой вместо головы. «Вызвать на бой» запускает прежнюю мини-игру, теперь за право поставить дизлайк. Управление — свайпы; своевременный свайп парирует, серия свайпов по открытому противнику наносит урон. Повреждения видны на модели. «Пусть играет» возвращает в меню.
- **Вторжение.** Приглашение от артиста с новым релизом. «Принять вызов» открывает ритм-игру с тремя жизнями, камнями, удерживаемыми клинками, парными нотами и ловушками. Здесь играет предоставленный музыкальный фрагмент. «Отказаться» возвращает в меню. Подробности — `src/rhythm/README.md`.
- **Закрыть.** Кнопка «Закрыть» в стартовом меню переходит на отдельную страницу с `textures/vid/cat.mp4`. Небольшой текстурный крест на рамке «Мимика» возвращает в стартовое меню. Видео заполняет большую вертикальную рамку с исходными пропорциями 784 × 1210, как на экране «Мимик». Изображение кадрируется по центру, а края растворяются под рамкой через мягкую маску. Видео играет inline с исходным звуком. Крест видео, Escape, нажатие на чёрный фон или окончание ролика возвращают в стартовое меню. Крест собран из существующих текстур: видимый размер 36 px при области нажатия 44 px. До перехода на страницу видео файл не загружается.

«Главная» в доке возвращает в выбор сценария. Каталог и «Моё» сохраняют прежний вид; отдельные страницы для них не реализованы. Состояние хранится в памяти вкладки. Перезагрузка возвращает меню.

## Оформление

Референсы: `textures/referance/first_page.png`, `mimic.png`, `dislike.png`, `vtorchenie.png`. На стартовом экране снова используется прежний процедурный шейдер камня с пеплом; параметры доступны в разделе DialKit «Камень и пепел». Остальные экраны имеют чёрный фон, иллюстрации растворяются в него через CSS-маски. Подложки кнопок стартового меню и мини-плеера сохраняют исходные пропорции `plas.webp` 357 × 119 (3:1): их высота зависит от ширины без растягивания текстуры. Место под мини-плеер пересчитывается вместе с его высотой; на низком экране меню допускает вертикальную прокрутку. Заголовок «Мимика» — 20/60 px Semibold; подписи — 20 px, кнопки приглашений — 24 px Medium, высота 74 px. Letter spacing −4%. Основные кнопки приглашений имеют обводку 1 px с градиентом от прозрачного к белому.

Файлы в `font/` — **Source Serif Pro** Regular и Semibold; они используются и в новом интерфейсе. Отдельного Source Serif 4/Medium в проекте нет: CSS задаёт вес 500 с подбором ближайшего доступного начертания. Размеры адаптируются на небольших экранах. Типографика мини-плеера и дока сохраняет их прежнюю иерархию.

Новые исходные PNG сохранены. В интерфейсе используются копии `textures/optimized/`: портреты WebP quality 88, диск quality 90, рамка без потерь с прозрачностью. `textures/vid/cat.mp4` используется без изменения. Настройки дока, белых масок, положения Play и металлического блика доступны в DialKit.

Эксперимент **«Слои и параллакс»** в DialKit включён по умолчанию. `enabled` переключает между исходными портретами и отдельными слоями фона/персонажа, подготовленными через встроенный ImageGen. `parallax` включает автоматическое медленное движение без мыши, касаний или гироскопа; `strength` задаёт амплитуду в px, `motionSpeed` — скорость движения. Фон и персонаж движутся в противоположных направлениях внутри неподвижной рамки. Рамка, крест, текст и Play остаются на месте. Блик рамки включается отдельно через `frame` в общем разделе **«Металлический блик»**, с общей яркостью, цветом и скоростью для всего металла.

`atmosphere`, `intensity`, `speed` управляют прозрачным WebGL-слоем между фоном и персонажем. Раздел **«Магия Мимика»** настраивает синие светящиеся завихрения: включение, яркость, цвет и чёткость (`definition`). В разделе **«Пепел Вторжения»** — прежний шейдер пепла с серыми частицами и редкими угольками: включение, количество, ветер, яркость и цвет угольков. Настройки сохраняются локально. При скрытой вкладке и во время боя эффекты приостанавливаются; reduced motion отключает движение и оставляет статичную атмосферу. Если WebGL недоступен, иллюстрации остаются видны. Пока новые изображения загружаются, показывается исходный портрет.

Четыре сгенерированных оригинала находятся в `textures/generated/`, их WebP-копии — в `textures/optimized/*-v1.webp`. Полные промпты и соответствие файлов записаны в `textures/generated/parallax-prompts.json`. Прежние портреты сохранены для сравнения и отключения эксперимента.

## Проверки и сборка

```sh
npm test
npm run check:render
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт `dist/`. Папку можно разместить на статическом хостинге, в том числе в подпапке сайта. Для просмотра нужен HTTP-сервер.

Тесты проверяют механику обеих игр, жесты, геометрию, отрисовку и сохранённые компоненты. `check:render` проверяет стартовое меню, три экрана, отдельную страницу inline-видео, отсутствие медиа на старте и наличие ресурсов. Автоматические проверки не заменяют визуальную проверку WebGL и жестов в Safari на телефоне.

## Структура

- `src/App.tsx` — вход в новый интерфейс.
- `src/ScenarioApp.tsx` — меню, маршруты сценариев, мини-плеер и запуск игр.
- `src/scenarios/` — главная мимика, превью боя, видео с котом и новые ресурсы.
- `src/scenarios.css` — новая композиция и типографика.
- `src/MiniPlayer.tsx`, `src/ui.tsx` — переиспользованные компоненты.
- `src/MimicStage.tsx`, `src/mimic/` — мимик, включая режим укуса кнопки.
- `src/DuelView.tsx`, `src/duel.ts`, `src/battle/` — бой за дизлайк.
- `src/RhythmGame.tsx`, `src/rhythm/` — ритм-игра вторжения.
- `src/MetalGlint.tsx` — общий металлический блик.
- `textures/`, `public/assets/`, `font/` — изображения, оригиналы, шрифты и лицензии.
- `src/Carousel.tsx`, `src/NativeSettings.tsx`, `src/NativeSpeech.tsx` и прежние стили сохранены как компоненты предыдущего прототипа; на новых экранах они не монтируются.
- `vendor/` — локальные архивы зависимостей с лицензиями; нужны для `npm ci`.

Исходники, ресурсы, тесты, `package-lock.json` и `vendor/` входят в Git. `node_modules/`, `dist/`, `.env`, логи и временные файлы исключены через `.gitignore`.
